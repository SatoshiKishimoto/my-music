# My Music — iPhone向け 個人用 音楽・動画プレーヤー（PWA）

HTML・CSS・JavaScriptだけで動くPWAです。Mac・Xcodeは不要で、GitHub Pagesでそのまま公開できます。
曲や動画はサーバーへ送らず、iPhoneの中（IndexedDB）に保存します。

## 機能
- **再生できる形式**：MP3・WAV・M4A・MP4・MOV（iPhoneのSafariが再生できる形式）。「＋ ファイルから追加」で「ファイル」アプリや写真ライブラリから複数選べます
- **音楽モード／動画モード**：プレーヤー上部で切り替え
  - 🎵 音楽モード：動画も音声だけで再生します。画面を消しても再生が続きやすく、ロック画面から操作できます
  - 🎬 動画モード：映像付きで再生します。ピクチャ・イン・ピクチャと全画面に対応。再生位置は切り替えても引き継がれます
- **音声の取り出し**：曲の「⋯」→「🎧 音声を取り出す」で、動画や音声ファイルから MP3（192／128kbps）または WAV を作成。iPhone内だけで処理します
- **「ファイル」アプリへの保存**：曲の「⋯」→「📁「ファイル」アプリに保存」、または取り出した音声の保存ボタンで共有メニューを開き、「"ファイル"に保存」を選びます
- **オフライン再生**：アプリ画面はService Workerでキャッシュ、曲・動画はIndexedDBに保存されるので、機内モードでも再生できます（YouTubeなどネット上の曲を除く）
- **音楽と動画をまとめたプレイリスト（フォルダ）管理**：歌手ごとのフォルダ分け、自動振り分け、ドラッグでの並べ替え、検索、「すべて／音楽／動画」の絞り込み
- **YouTubeなどの共有URL**：YouTube（youtu.be／youtube.com／YouTube Music／Shorts）は公式の埋め込みプレーヤーで再生。Googleドライブ・Dropboxの共有リンク、音声・動画ファイルの直リンクも登録できます
- **URLからの保存**：「端末に保存してオフラインでも再生する」にチェックするか、URL曲の「⋯」→「⬇ 端末に保存」で、配布元が直接ダウンロードを許可しているファイルを保存できます
- **バックグラウンド再生とロック画面操作**（iOSが許す範囲で）：Media Session APIで曲名・アートワーク・再生位置を表示し、再生／一時停止／曲送り／シークに対応
- **ファイル形式の表示**：一覧に形式バッジ（MP3・WAV・M4A・MP4・MOVなど）、再生中の表示に形式、曲の「⋯」に形式・サイズ・元のファイル名・長さを表示。検索欄に「mp4」などと入れると形式で絞り込めます
- **早送り・巻き戻し**：「10秒戻る」「10秒進む」ボタン（ミニプレーヤーにもあり）（PCではキーボードの ← → でも操作可）。ロック画面からも前後にスキップできます
- **ミニプレーヤー**：下の方へスクロールしてプレーヤーが見えなくなると、画面下に曲名・前の曲・再生/一時停止・次の曲・進行バーを固定表示。タップでプレーヤーに戻ります
- **音量**：iPhoneではWebアプリから音量を変えられないため、スライダーを隠して本体の音量ボタンを案内します（PCではスライダーで調整できます）
- **曲ごとの音量をそろえる**：プレーヤーのスイッチをオンにすると、保存した曲・動画の大きさ（ラウドネス、ITU-R BS.1770方式）を測り、目標 -16 LUFS に合わせた音声（MP3 256kbps）を作って再生に使います。ピークが大きい曲はリミッターで音割れを防ぎます。差が1dB未満の曲は元のまま（容量を使いません）。動画は映像はそのまま、音声だけを差し替えます。ふつうの再生のしくみを使うため、バックグラウンド再生・ロック画面の操作もそのまま使えます（`normalize.js`・`norm-worker.js`）
- サムネイル自動取得（動画は1コマ、MP3/M4Aは埋め込みアルバムアート）、シャッフル・リピート、保存状況の確認欄

## 公開方法（GitHub Pages）
1. このフォルダの中身をすべてリポジトリのルートに置く。
2. Settings → Pages → Deploy from a branch → main / (root) → Save。
3. `https://ユーザー名.github.io/my-music/` をiPhoneのSafariで開き、共有メニュー →「ホーム画面に追加」。

## ファイル構成
| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` | 画面 |
| `app.js` | 再生・ライブラリ・保存・モード切替などの本体 |
| `extract.js` | 音声の取り出し（Web Audio APIでデコード → WAV作成／MP3変換の呼び出し） |
| `mp3-worker.js` | MP3変換（Web Worker） |
| `vendor/lame.min.js` | MP3エンコーダー lamejs 1.2.1（LGPL-3.0、`vendor/lamejs-LICENSE.txt`） |
| `sw.js` | オフライン用のService Worker |

## iPhoneでの制限と注意
- **保存容量**：曲・動画はアプリ内に元ファイルとは別にコピーされます。動画は容量が大きいので、「保存状況を確認」で使用量を確認し、不要なものは削除してください。空きが足りないときは保存前に確認が出ます。
- **保存場所**：ホーム画面に追加したアプリとSafariで開いたページは保存場所が別です。ホーム画面のアプリから使ってください。Claudeアプリなど他のアプリ内のブラウザでは、閉じると保存が消えることがあります。
- **ピクチャ・イン・ピクチャ**：iOSの制限により、ホーム画面に追加したアプリでは使えません（Safariで開いたときだけ使えます）。ホーム画面のアプリではボタンを隠し、代わりに案内を表示します。
- **バックグラウンド再生**：音はいつも音声専用の要素から出し、動画モードの映像は消音した動画を音声に合わせて表示しています。iPhoneはほかのアプリに切り替えると映像を止めますが、音はそのまま続き、アプリに戻ると映像が音声の位置に追いついて再開します（iOSの設定・バージョンによっては止まる場合があります）。
- **音声の取り出し**：ファイル全体をメモリに読み込むため、長い動画（目安400MB以上）は失敗することがあります。WAVは1分あたり約10MBになります。iPhoneのSafariが再生できない音声形式からは取り出せません。
- **「ファイル」アプリへの保存**：共有メニューは画面をタップした瞬間にしか開けないため、変換が終わってから保存ボタンを押す流れになっています。共有メニューが使えない環境では「ダウンロード」フォルダに保存されます。
- **URLからの保存**：配布元のサーバーがアプリからのダウンロード（CORS）を許可しているファイルだけ保存できます。許可されていない場合は保存せず、URLのまま再生します（GoogleドライブなどはWebアプリからのダウンロードを許可していないため、Safariでダウンロードしてから「ファイルから追加」してください）。

## YouTubeについて
- YouTube公式の埋め込みプレーヤー（IFrame Player API）で再生します。動画・音声のダウンロードや音声の抜き出しは、YouTubeの利用規約で禁止されているため実装していません。
- YouTubeは画面ロック中やバックグラウンドでは再生が止まり、ロック画面からの操作もできません。オフラインでは再生できません。
- iOSの自動再生の制限により、曲送りでYouTubeに切り替わったとき再生が始まらない場合があります。その場合は動画の▶をタップしてください。
- 投稿者が埋め込みを許可していない動画は再生できません。Spotify・Apple Music・SoundCloudなどのリンクは再生できません。

## ローカルでの動作確認
このフォルダで `python -m http.server 8000` を実行し、PCのブラウザで `http://localhost:8000` を開きます（Service WorkerはHTTPSで公開したときに有効になります）。

※ GitHub Pagesで公開した内容は誰でも見られます。音楽・動画ファイルや秘密のURLはリポジトリに置かないでください。
