# My Music — iPhone向け個人音楽プレーヤー

## 機能
- iPhoneの「ファイル」アプリからMP3/WAV/M4A、動画（MP4/MOV、音声のみ再生）などを複数選択して再生
- URLから曲を登録・保存（localStorage）：YouTube（youtu.be／youtube.com／YouTube Music／Shorts）の共有リンク、Googleドライブ・Dropboxのファイル共有リンク、HTTPSの音声ファイル直リンクに対応。共有メニューでコピーした「タイトル＋URL」の文章をそのまま貼り付けてもOK
- 曲順の並べ替え（≡をドラッグ、または▲▼ボタン。Web曲の順番は保存されます）
- サムネイル表示（動画は1コマ、MP3/M4Aは埋め込みアルバムアートを自動取得）
- 追加した曲はアプリ内（IndexedDB）に保存され、次回起動時も自動で読み込み（選び直し不要）
- 歌手ごとのフォルダ（プレイリスト）分け：曲の「⋯」から移動、「✨ 歌手名で自動振り分け」で曲名（「歌手 - 曲名」形式）やMP3/M4Aの歌手タグから一括振り分け。フォルダを開いて再生するとそのフォルダ内だけを順番に再生
- 曲名・歌手名で検索
- 再生・一時停止・曲送り・シーク・音量・シャッフル・全曲/1曲リピート
- iOSが対応する範囲でロック画面操作（Media Session API）
- ホーム画面に追加可能なPWA

## 公開方法（GitHub Pages）
1. GitHubで新規リポジトリ（例: `my-music`）を作る。
2. このフォルダの **中身をすべて** リポジトリのルートにアップロードする。
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
4. 発行された `https://ユーザー名.github.io/my-music/` をiPhoneのSafariで開く。
5. Safariの共有メニュー → 「ホーム画面に追加」。

## 注意事項
- 音楽ファイルをサーバーへアップロードしません。追加した曲はiPhone内のアプリ専用領域に保存されます（元のファイルとは別にコピーされるため、その分の容量を使います）。
- iOSのWebアプリは「ファイル」アプリの特定フォルダを自動で読むことはできません。新しい曲は「＋ ファイルから追加」で一度だけ追加してください。
- ホーム画面に追加したアプリと、Safariで開いたページは保存領域が別です。普段使う方で曲を追加してください。
- Web曲の登録情報はブラウザのlocalStorageに保存されます。端末データ消去やプライベートブラウズ等で消えることがあります。
- Web曲には **直接再生できるHTTPS音声URL** が必要です。YouTubeの視聴ページやクラウドストレージの共有ページURLは通常そのままでは再生できません。配信サーバー側の制約、認証、CORS、対応コーデック等によって再生できない場合があります。
- iPhone Safariの音声出力音量は端末の物理ボタンでの調整が必要な場合があります。
- バックグラウンド再生・ロック画面の操作はiOSバージョンや省電力設定等によって制限されることがあります。
- アプリ画面はキャッシュされますが、Web上の音声ファイル自体はオフライン保存されません。
- GitHub Pagesで公開したHTML/CSS/JSは公開情報です。**音楽ファイルや秘密のURL、認証情報をリポジトリにアップロードしないでください。**

## YouTubeリンクについて
- YouTubeはYouTube公式の埋め込みプレーヤー（IFrame Player API）でアプリ内に動画を表示して再生します。音声だけを抜き出す方法は利用規約で禁止されているため使っていません。
- iPhoneの制限により、YouTubeの曲は画面ロック中やバックグラウンドでは再生が止まります。ロック画面からの操作もできません。
- iOSでは自動再生が制限されるため、曲送りでYouTubeの曲に切り替わったときなどに再生が始まらない場合があります。そのときは動画の▶をタップしてください。
- 投稿者が埋め込みを禁止している動画（一部の公式MVなど）は再生できません。
- Spotify・Apple Music・SoundCloudなどのリンクは、仕組み上このアプリでは再生できません。
- Googleドライブは「リンクを知っている全員」に共有されたファイルのみ再生できます（大きなファイルは再生できない場合があります）。

## ローカルでの動作確認
`python -m http.server 8000` をこのフォルダで実行してPCブラウザから `http://localhost:8000` を開きます。iPhoneでPWAとして使う場合はHTTPS公開してください。
